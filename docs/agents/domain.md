# Domain docs

This is a single-context project.

## Before exploring

- Read `CONTEXT.md` at the repo root when it exists.
- Read relevant records under `docs/adr/` when they exist.
- If either path does not exist, continue without creating it. The domain-modeling skill creates these files only when the project has terms or decisions to record.

## Vocabulary

Use the terms defined in `CONTEXT.md`. If a needed concept is absent, check whether the project needs a new domain term before inventing one.

## Conflicts

Call out any plan or change that conflicts with an existing record under `docs/adr/`.
